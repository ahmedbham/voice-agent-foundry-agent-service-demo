## Objectives
- create a demo for [Voice Agent with Foundry Agent Service](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/voice-live-agents-quickstart?tabs=windows&pivots=programming-language-python)

## Requirements
- Python 3.10 or later
- Foundry Account and project are already set up. Reuse the same Foundry project for this demo.
- use of `azd` for any Azure resource provisioning and deployment.
- enable end-to-end testing for the demo.
- latency metrics capture.
